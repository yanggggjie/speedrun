# speedrun 图标

| 文件 | 作用 |
|---|---|
| [`icon.py`](icon.py) | **源文件**：所有参数都在里面，只用 python3 标准库 |
| [`icon.svg`](icon.svg) | 由 `icon.py` 生成并提交，不要手改 |
| [`make-icons.mjs`](make-icons.mjs) | 一条命令：先跑 `icon.py` 生成 SVG，再用无头 Chrome 出 `skills/spr/src/chrome-extension/icons/` 下 16、32、48、128 四个 PNG |

```bash
node brand/make-icons.mjs
```

## 一句话

**一个折成闪电的 S。** S 和闪电的走向一样：右上 → 左 → 右 → 左下。把 S 的弯折成硬角、两端收成尖，就同时像两者。

## 设计原则

1. **用名字做形状。** S 来自 speedrun，闪电来自「快」，不借光标、箭头、浏览器窗口这类通用符号。
2. **两种读法都要成立。** 右上和左下两个缺口让它读成 S，尖角和斜边让它读成闪电。
3. **中心对称。** 图形关于画布中心 `(64, 64)` 中心对称，转 180° 和自己重合，这是字母 S 本身的特征。
4. **配色也像闪电。** 黄底黑形，和 ⚡️ 一样的黄色。
5. **最小尺寸优先。** 先在 16 像素下判断，再看 128 像素。

## 构成与规格

画布 `128 × 128`，圆角矩形 `rx = 30`，四角透明。只有两层，都是纯色：黄色底，墨黑闪电 S。

### 闪电 S 的轮廓

只写前一半的 4 个顶点，另一半由中心对称得到（`(x, y) → (128 − x, 128 − y)`），一共 8 个顶点：

| 序号 | 顶点 | 含义 |
|---|---|---|
| 0 | `(112, 12)` | 右上尖角 |
| 1 | `(44, 12)` | 顶边左端 |
| 2 | `(18, 70)` | 左侧最外点 |
| 3 | `(76, 70)` | 左下缺口的最深处，`x` 越大缺口越深、越像 S |
| 4 到 7 | 0 到 3 的中心对称点 | `(16, 116)`、`(84, 116)`、`(110, 58)`、`(52, 58)` |

## 品牌色

| 名称 | 值 | 用在哪里 |
|---|---|---|
| 闪电黄 | `#FFD60A` | 主强调色，一个画面里只用一处，最多两处 |
| 墨黑 | `#17171C` | 黄色上的图形和文字；深色背景；浅色背景上的文字 |

选黄黑的理由：和 ⚡️ 的配色一样，一眼就有「快」的感觉；黑在黄上对比最强，16 像素下也清楚；整块黄色在浅色和深色工具栏上都显眼。

## 迭代记录

| 阶段 | 做法 | 结果 |
|---|---|---|
| 一 | 浏览器窗口加光标（旧图标） | 只说了「在浏览器里」，和同类工具分不开 |
| 二 | 弯路加直线箭头、s 加箭头，放在圆角底块上 | 有含义，但是「底板加图案」，不够整体 |
| 三 | 白线把整面切成两块，顶部上扬冲出右上角 | 不够像 S，线不够粗 |
| 四 | 标准 S 字形，线宽 22 到 28 | 像 S 了，但顶部上扬不要 |
| 五 | 中心对称，两端水平出血 | 最像 S，但几段贝塞尔拼接，不够流畅 |
| 六 | 整条 S 换成均匀三次 B 样条，红黑两块 | 流畅，但只像 S，没有快的感觉 |
| 七 | S 折成闪电，黄底黑形（本版本） | 最终 |

第七阶段比较过六个候选：硬折 S、尖头弯 S、黄底反色、黄橙双色、两端出血、竖长闪电。尖头弯 S 闪电感最弱，竖长闪电 S 感最弱，黄橙双色的橙色在 16 像素、深色工具栏上偏暗。最终选黄底反色：S 和闪电最平衡，整块黄色最像 ⚡️，小尺寸下最显眼。

## 小尺寸检查

每次改动后看 16、32、48、128 四个 PNG，16 像素放在白底（浅色工具栏）和 `#202124`（深色工具栏）上：

1. 16 像素下还认得出 S 吗？
2. 还认得出闪电吗？两个缺口没有糊掉吗？
3. 黄色底在两种背景下都分得开吗？

## 如何修改

1. 改 `brand/icon.py` 里的常量（不要手改 `icon.svg`）。
2. 运行 `node brand/make-icons.mjs`。
3. 按上面的方法检查小尺寸。
4. `node skills/spr/setup.js` 重装，扩展会自动重新加载。
