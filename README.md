# TwoCursor

> it takes two to browse —— 一个浏览器，两个光标：一个人，一个 agent。

人和 agent 共用同一个浏览器。人可以做，agent 也可以做；agent 做事时人可随时插手，agent 能感知"现在是人在帮我"。

**状态：第一阶段已实现（常驻录制和只读观察）。** 代码起点是 [twocursor](https://github.com/yanggggjie/TwoCursor)（Apache-2.0）；新增 `twocursor sites / tabs / log / sql / snapshot / wait / status`，见 `skills/twocursor/SKILL.md` 第 9 节。agent 操作用户正在用的标签页、租约还没做。设计与路线见 [docs/DESIGN.md](docs/DESIGN.md)，实验记录见 [docs/EXPERIMENTS.md](docs/EXPERIMENTS.md)，换机器继续请先读 [docs/CONTEXT.md](docs/CONTEXT.md)。
